# Summary Report: “AI Agents, Prompt Engineering, and AIoT Projects on AWS”

### Event Objectives

- Introduce the concept of AI Agents and their role beyond traditional LLM usage  
- Demonstrate how prompt engineering improves output quality and efficiency  
- Present real-world AIoT architectures combining hardware and AWS services  
- Provide practical insights for building AI-powered cloud applications

### Key Highlights

#### From LLMs to AI Agents

- Traditional LLMs → Limited to single-step responses  
- AI Agents → Multi-step reasoning, tool usage, and contextual decision-making  
- Integration with external services → More practical and autonomous systems  

#### Building AI Agents with Strands

- **Core components**: System prompts, tool calling, knowledge base  
- **Agent workflow**: Input → reasoning → tool usage → output  
- **Advantages**: Faster development compared to manual orchestration  

#### Prompt Engineering & Optimization

- **Key elements**: Role, task, context, constraints, output format  
- **Best practices**:  
  - Be specific and structured  
  - Avoid ambiguity  
  - Separate prompt sections clearly  
- **Advanced techniques**: Chain-of-Thought, RAG, role prompting  
- **Cost awareness**: Better prompts → fewer tokens → lower cost  

#### AIoT System Architecture

- **Use case**: Locker Management System  
- **Hardware layer**: Raspberry Pi, Arduino, RFID, sensors, camera  
- **Cloud layer (AWS)**:  
  - AWS IoT Core → Device communication  
  - Lambda → Event processing  
  - DynamoDB → Data storage  
  - Rekognition → Face recognition  
- **Goal**: Automate operations and improve system efficiency  

#### Real-world Application Example

- **Plutus App**: Financial budget management system  
- Demonstrates how cloud + AI can support practical business use cases  

### Key Takeaways

#### AI Architecture Trend

- AI is evolving from simple prompt-based interaction → agent-based systems  
- Agents enable automation, reasoning, and system integration  

#### Importance of Prompt Design

- Prompt engineering is a technical skill, not just writing  
- Well-structured prompts improve:  
  - Accuracy  
  - Consistency  
  - Cost efficiency  

#### Cloud + AI + IoT Integration

- AWS provides a complete ecosystem for building AIoT systems  
- Combining edge devices with cloud services enables scalable solutions  

### Applying to Work

- **Prompt Engineering**:
